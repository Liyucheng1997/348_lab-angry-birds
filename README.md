# 愤怒的小鸟（HTML5 版）

纯前端实现，没有构建步骤。物理引擎用 Planck.js（Box2D 的 JS 移植版），已放在 `lib/` 里，可离线运行。

## 运行

双击打开 `index.html` 即可；也可以起一个本地服务器：

```bash
npx http-server -p 8348
```

## 操作

- 按住弹弓上的小鸟往后拉，松手发射
- 飞行中点击屏幕（或按空格）释放技能
- 拖动画面平移，滚轮或双指捏合缩放
- `R` 重来，`Esc` 暂停

## 小鸟

| 小鸟 | 技能 |
| --- | --- |
| 红鸟 | 战吼，把附近的方块震开 |
| 蓝鸟 | 一分为三，对冰块特别有效 |
| 黄鸟 | 加速冲刺，对木头特别有效 |
| 炸弹鸟 | 点击引爆，撞击后也会自动爆炸，能炸碎石头 |
| 白鸟 | 投下炸弹蛋，自己往上飞走 |
| 大红鸟 | 体重大，震天怒吼 |

## 文件结构

- `js/art.js`：所有美术都用 Canvas 程序化绘制（小鸟、猪、木/石/冰/TNT 材质与裂纹、地形、弹弓、视差背景）
- `js/levels.js`：12 个关卡，用一套简单的搭建 API 定义，方便自己加新关卡
- `js/game.js`：物理、伤害、技能、相机、粒子特效、界面和存档
- `js/audio.js`：WebAudio 实时合成的音效和背景音乐
